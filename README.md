# impak-assinatura

Logo usado nas assinaturas de e-mail da IMPAK Comercial Importadora.

## NÃO APAGUE, NÃO RENOMEIE E NÃO TORNE PRIVADO

Todas as assinaturas de e-mail da equipe carregam o logo deste endereço:

https://impak-site.github.io/impak-assinatura/logo-impak.png

Se este repositório for apagado, renomeado ou ficar privado, o logo some das assinaturas de todos.

## Para trocar o logo

Substitua o arquivo logo-impak.png por outro com o mesmo nome e o mesmo tamanho (160 x 68 px, fundo branco).
